# Student Management System using Stack (C)

## Description
This project is a console-based application developed in C for managing students using a stack (pile) data structure.

It allows the user to perform multiple operations such as adding, removing, searching, and organizing student records.

---

## Technologies Used
- Language: C
- Data Structures: Stack (Linked List)

---

## Features
- Initialize a stack
- Push (add) a student
- Pop (remove) a student
- Display all students
- Search for a student by CNE
- Show the top element of the stack
- Insert a student at the base of the stack
- Reverse the stack
- Delete a student by CNE
- Undo last deletion (history system)
- Count students by first letter of first name
- Display students with a specific name length
- Sort students temporarily by CNE
- Display stack size

---

## Concepts Covered
- Dynamic memory allocation (malloc, free)
- Linked lists
- Stack operations (LIFO)
- Pointers manipulation
- String handling in C
